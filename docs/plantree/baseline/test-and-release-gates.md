# 验证门槛

实现后按阶段验证：工具限制与 Prompt、双会话隔离、真实 ERP 查询/写入、知识引用/版本、审批校验、幂等、暂停重启恢复、Worker 重投递与取消、在线/批处理混合负载。

同时报告延迟、吞吐、CPU/RAM/显存与正确性；不以 Rust 实现或组件宣传数据推断整体性能。当前只有本项目 PostgreSQL 与业务 API 的本地验证；尚未执行 JCode/Cube/ERP/知识库集成或性能测试。

基础验证命令：`npm run check`。真实 PostgreSQL 独立临时库覆盖租户/角色隔离、并发方案、旧版本审批、重复审批、审计失败回滚、应用重建、令牌撤销和迁移就绪状态；构建包含 SQL 文件。此验证不等于 ERP 写入幂等或沙箱恢复验收。
